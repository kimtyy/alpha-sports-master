## 기준과 범위
- 검수 기준: master 27a4d605e9b30a6ffb71938a00d445359e2ec72b.
- 2026-10-25 운영 API에는 이 저장소에 없는 Elo/rawIds/확장 리그 구현이 관측됐다.
- master의 GitHub 상태에는 스포츠와 정치 프로젝트 각각 Vercel 배포 성공 이력이 있다. 이것이 현재 production 소스를 증명하지는 않는다.
- 따라서 이 변경은 저장소 기준의 검토용 수정이다. 현재 운영 앱에 그대로 배포하면 미동기화된 기능이 사라질 수 있다. 먼저 Vercel production 배포의 source/commit과 로컬 최신 소스를 대조해야 한다.

## 변경 동작
- 예제 경기로 초기화하지 않는다. 데이터 연결 실패는 HTTP 503과 오류 화면으로 구분한다.
- HTTP 200 내부 API 오류도 실패 처리한다. 리그 일부 실패는 전체 수집 실패로 표시한다.
- 한국시간 기준 날짜와 리그별 시즌을 사용한다. 시즌 시작 월은 유럽 7월, K리그 연도로 설정한 MVP 규칙이며 대회 메타데이터 연동 전까지 경계 기간 확인이 필요하다.
- 배당 페이지를 모두 수집하고 유효한 실제 가격만 사용한다. 배당 수집 실패는 UNAVAILABLE이며 UI에서 미수집으로 표시한다.
- 호환성을 위한 미수집 배당 0은 계산에 사용하지 않는다. Kelly 유틸리티도 1 이하/비유한 배당을 거부한다.
- 예측 엔드포인트와 채팅 추천은 MODEL_UNAVAILABLE/503을 반환한다. 모델 호출·모의 복구·고정 확률·신뢰도·추천액을 제거했다.
- 분석 화면에는 출처, 수집 시각, 경기 상태, 실제 배당만 표시한다.
- 기존 관심 경기와 수동 적중 입력은 유지하지만 AI 모델 성능이 아님을 명시한다. 공식 결과 자동 판정은 아직 구현하지 않았다.
- /api/version은 Git 배포 SHA가 있을 때만 공개하고, 없으면 unverified로 표시한다. 이것만으로 비-Git 배포의 소스가 검증되지는 않는다.

## 긴급 키 교체 (소유자 작업)
공개 저장소의 공백으로 시작하는 환경파일에 비어 있지 않은 GEMINI_API_KEY/APIFOOTBALL_KEY가 존재했다. 유효성을 시험하거나 값 자체를 출력하지 않았다. 환경파일 두 개는 새 트리에서 제거하고 재추적 방지 규칙을 추가했다.
1. Google/API-Football에서 노출된 키를 폐기·재발급한다.
2. 필요한 새 키를 올바른 Vercel 프로젝트 환경변수에만 설정한다. 이 수정에서는 Gemini 호출이 비활성화되어 있다.
3. 이전 커밋에도 비밀값이 남으므로 별도 이력 정리와 기존 복제본 정리가 필요하다. 새 PR에서 파일을 삭제하는 것만으로 노출이 해결되지 않는다.
4. .env.vercel.tmp의 Vercel OIDC 토큰도 노출 이력으로 검토한다. 현재 만료/권한 상태는 확인하지 않았다.
5. Supabase anon 키의 공개만으로 비밀키 유출로 단정하지 않는다. 운영 RLS/권한 정책은 별도로 검증한다.

이력 강제 재작성, 키 폐기, production 환경변수 수정 및 배포는 이 PR에 포함하지 않는다.
